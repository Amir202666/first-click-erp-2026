# نقل كل الإعدادات والتنسيقات من الأونلاين إلى الأوفلاين

نقل **الإعدادات + التنسيقات (قوالب الطباعة) + البيانات المرجعية + دليل الحسابات**
من سيرفر الإنتاج (`firstclickerp.top`) إلى النسخة الأوفلاين المحلية (MySQL/XAMPP)
**بدون** نقل الفواتير أو العمليات.

الاتجاه: **السيرفر (أونلاين) → جهازك (أوفلاين)**.

---

## 0) تجهيز الأوفلاين محلياً (مرة واحدة) — تم إعداده

- MySQL يعمل عبر XAMPP، وقاعدة `firstclick_local` جاهزة.
- `backend\.env` مضبوط على MySQL (نسخة SQLite محفوظة في `backend\.env.sqlite.bak`).
- تم `php artisan migrate` + `php artisan local:setup` (الشركة `first-company` موجودة).

لتشغيل MySQL لاحقاً إن توقف:

```bat
scripts\fix-xampp-mysql.bat
```

---

## 1) على السيرفر (Hostinger Browser Terminal) — تصدير من الأونلاين

> يتطلب أن يكون كود السيرفر محدثاً (فيه أمر `tenant:sync-settings`). إن لم يوجد:
> `cd /var/www/erp && git pull origin main`

```bash
cd /var/www/erp/backend

# إعدادات + قوالب الطباعة/المستندات
php artisan tenant:sync-settings export --slug=first-company --file=storage/app/exports/settings_first-company.json

# البيانات المرجعية (عملات، فروع، مراكز تكلفة، وحدات، فئات، طرق دفع)
php artisan tenant:sync-reference export --slug=first-company --file=storage/app/exports/reference_first-company.json

# دليل الحسابات
php artisan accounts:export-chart --slug=first-company --output=storage/app/exports/chart_first-company.json
```

---

## 2) تنزيل الملفات (Hostinger File Manager)

نزّل الملفات الثلاثة من:

```
/var/www/erp/backend/storage/app/exports/
```

- `settings_first-company.json`
- `reference_first-company.json`
- `chart_first-company.json`

وضعها على جهازك في:

```
d:\erp projects\first click\backend\storage\app\imports\
```

---

## 3) الاستيراد إلى الأوفلاين (جهازك)

أمر واحد يستورد الثلاثة بالترتيب الصحيح:

```bat
scripts\import-from-online.bat first-company
```

أو يدوياً من مجلد `backend`:

```bat
php artisan accounts:replace-chart  --slug=first-company --file=storage/app/imports/chart_first-company.json --force
php artisan tenant:sync-reference   import --slug=first-company --file=storage/app/imports/reference_first-company.json
php artisan tenant:sync-settings    import --slug=first-company --file=storage/app/imports/settings_first-company.json
```

- إضافة `--prune` لأمر `tenant:sync-settings` تحذف القوالب/الإعدادات المحلية غير الموجودة في ملف الأونلاين
  (مطابقة تامة). بدونها = إضافة/تحديث فقط (الأكثر أماناً).

---

## 4) التشغيل والتحقق

```bat
scripts\local-dev.cmd
```

ثم افتح `http://localhost:5173` وتحقق من:
- الإعدادات (بيانات الشركة، العملات، الفروع…)
- تنسيقات/قوالب الطباعة (فاتورة، سند قبض/صرف…)

---

## ملاحظات

- هذه العملية **لا تنقل** الفواتير أو القيود أو العملاء/الموردين.
  لنسخة كاملة (كل شيء) استخدم مسار قاعدة البيانات الكامل بدلاً من ذلك.
- بيانات الدخول المحلية: الشركة `first-company` / المستخدم `firstclick-erp` / `FirstClickERP`.
- للرجوع إلى SQLite: انسخ `backend\.env.sqlite.bak` فوق `backend\.env`.
